# Code of Conduct

BASKA SEND aims to provide a respectful, constructive and welcoming community.

Be considerate, discuss technical disagreements respectfully, provide actionable feedback, and avoid harassment, discrimination, threats, bullying, spam and sharing another person's private information.

Maintainers may remove abusive content and restrict repeated violations to keep collaboration productive. Report conduct concerns privately to the repository owner using their public contact channels. Security issues should follow [SECURITY.md](SECURITY.md).

This applies to project issues, pull requests, reviews and other project spaces.
