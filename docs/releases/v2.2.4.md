# BASKA SEND v2.2.4

**SendToCom** is a lightweight, single-file Python messaging and file-transfer hub for devices on a trusted local network. The host runs on Windows and serves a responsive WebApp to nearby devices.

### Highlights

- Private chat, public room, reply and message delivery/read states.
- Controlled document/image transfer, file previews, and organized local download folders.
- Main/device PIN authentication, temporary pairing QR/code, and access revocation.
- Native Windows popup notifications with reply, copy, sounds and system tray controls.
- SQLite message history and responsive dark/light WebApp.
- Core functions use the Python standard library; no mandatory pip dependencies.

### Installation

1. Install **Python 3.10+** on **Windows 10/11**.
2. Download **BASKA-SEND-v2.2.4-source.zip** below and extract it to a permanent location.
3. Run `py -3 SendToCom.py --setup` from PowerShell.
4. Follow the setup prompts, then open the LAN URL displayed by the application.

This release is a **Python source ZIP**, not an executable installer. The included **SHA256SUMS.txt** provides the archive checksum for download integrity checks.

### Security notice

**LAN-only, trusted networks.** The application's built-in server uses **unencrypted HTTP**. **Do not port-forward port 8765, expose it to the internet, or deploy it on untrusted Wi-Fi.** Review [SECURITY.md](https://github.com/baska-pro/sendtocom/blob/main/SECURITY.md) and [Installation](https://github.com/baska-pro/sendtocom/blob/main/docs/INSTALLATION.md) before using it.
